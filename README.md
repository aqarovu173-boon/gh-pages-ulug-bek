## ⚙️ O'rnatish va ishga tushirish

### 📋 Talablar

- Zamonaviy brauzer (Chrome, Firefox, Edge, Safari)
- [Git](https://git-scm.com/) *(loyihani yuklab olish uchun)*

### 📥 O'rnatish

**1. Repozitoriyni yuklab oling:**

```bash
git clone https://github.com/aqarovu173-boon/gh-pages-ulug-bek.git
```

**2. Loyiha papkasiga kiring:**

```bash
cd gh-pages-ulug-bek
```

### ▶️ Ishga tushirish

Hech qanday o'rnatish kerak emas. `index.html` faylini brauzerda oching:

```bash
# macOS
open index.html

# Linux
xdg-open index.html

# Windows
start index.html
```

Yoki mahalliy server bilan ishga tushiring (Python o'rnatilgan bo'lsa):

```bash
python -m http.server 8000
```

So'ng brauzerda `http://localhost:8000` manzilini oching.

### 🌍 GitHub Pages'da e'lon qilish

1. Repozitoriyning **Settings → Pages** bo'limiga kiring
2. **Source** qismida kerakli branch'ni (`main`) va `/ (root)` papkasini tanlang
3. **Save** tugmasini bosing
4. Bir necha daqiqadan so'ng sayt shu manzilda ochiladi:
   `https://aqarovu173-boon.github.io/gh-pages-ulug-bek/`
